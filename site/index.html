An operating system that proves itself.

KaadzOS is a minimal Debian 13 image with a hand-built Sway desktop, a pure-black AMOLED theme rendered from one palette, and an on-demand pack system. Every push is built, booted on BIOS and UEFI, and installed to disk before anything ships.

01 / The image

Small by design. No language runtime, no recommends, nothing it cannot justify — a working Wayland desktop, and room for what you add later.

The base image is Debian trixie built from the archive with --apt-recommends false: kernel, firmware, NetworkManager, Sway, Waybar, foot, fuzzel, mako and the lean defaults. Everything heavier is opt-in.

Eight declarative packs add AI tooling, Android apps, Windows apps, dev chains, gaming, creative apps, privacy tools or Cloudflare's client — through one idempotent command, from a terminal or the $mod+a menu.

02 / The desktop

Sway, themed
down to the console.

Session
Sway on Wayland. Waybar, foot, fuzzel, mako and swaylock, driven from the Super key.
Theme
One file, theme/palette, renders the boot splash, boot menus, Sway, Waybar, foot, fuzzel, mako, swaylock, GTK3/4, Qt6ct, the wallpaper and the console colours in the same pure-black, white and grey palette as this site.
Installer
Calamares unpacks the live squashfs onto disk and repairs the copy in place. Launch it from the Install button in Waybar, with Super+I, or by running kaadzos-install. The installed system boots through greetd into the same session.
Defaults
GNOME Web, Thunar, Mousepad, imv and zathura. Screen recording with wf-recorder on $mod+Print.
Memory
zram swap (zstd) sized at half of RAM with swappiness 180. The boot test reports idle RAM on every run.
Secure Boot
Debian's signed shim and GRUB ship in the image, so the installed system boots with Secure Boot enabled. The live USB still needs it off.

The boot test waits for a real swaymsg IPC reply on the serial console, dumps the framebuffer and fails if swaynag is running — a red bar means the config emitted an error. The install test drives Calamares with wtype on a blank disk, then boots the installed system without the ISO.

Write

# replace sdX — this erases it
sudo dd if=KaadzOS-trixie-amd64.iso \
  of=/dev/sdX bs=4M status=progress \
  oflag=sync

Hybrid image: the same file boots from a USB stick under BIOS or UEFI. On Windows, write it with Rufus or balenaEtcher in DD mode. Installed systems can opt into the signed KaadzOS archive at iso.kaadzos.pages.dev/apt; the source stanza and setup are in the APT repository notes.
