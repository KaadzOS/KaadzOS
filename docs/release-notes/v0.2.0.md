KaadzOS 0.2.0 is the first release with the optional signed APT archive and
the Cloudflare R2 download mirror. The desktop session, installer and on-demand
packs are the same as 0.1.0; this release makes the package archive and the ISO
available at stable, CI-published URLs.

## Download

- `KaadzOS-trixie-amd64.iso` (~1.4 GB, hybrid ISO)
- `KaadzOS-trixie-amd64.iso.sha256`
- `KaadzOS-trixie-amd64.iso.sha256.asc` (signed checksum)
- `kaadzos-archive-keyring.asc` (the archive/signing public key)

The ISO is mirrored at:

    https://iso.kaadzos.pages.dev/releases/v0.2.0/

Verify before writing to a USB stick:

    sha256sum --check KaadzOS-trixie-amd64.iso.sha256

To verify the signature as well, import the release key and check the checksum
file:

    curl -fsSL https://iso.kaadzos.pages.dev/releases/v0.2.0/kaadzos-archive-keyring.asc \
      | gpg --import
    gpg --verify KaadzOS-trixie-amd64.iso.sha256.asc KaadzOS-trixie-amd64.iso.sha256

The image is hybrid: the same file boots from a USB stick under BIOS or UEFI.
Secure Boot is supported on the installed system; the live image still requires
Secure Boot to be disabled.

## Optional APT archive

The signed archive is served from the same public host as the ISO mirror:

    https://iso.kaadzos.pages.dev/apt

Enable it on a Debian 13 (trixie) system with:

    sudo install -d -m 0755 /usr/share/keyrings
    curl -fsSL https://iso.kaadzos.pages.dev/apt/kaadzos-archive-keyring.asc \
      | sudo gpg --dearmor -o /usr/share/keyrings/kaadzos-archive-keyring.gpg
    curl -fsSL https://iso.kaadzos.pages.dev/apt/kaadzos.sources \
      | sudo tee /etc/apt/sources.list.d/kaadzos.sources >/dev/null
    sudo apt update
    sudo apt install kaadzos-pack-defs

`kaadzos-pack-defs` installs the canonical pack definitions under
`/usr/share/kaadzos/packs`. The archive is optional: the base image does not
depend on it, and the publishing jobs skip cleanly when the Cloudflare and GPG
credentials are not configured.

The archive is published by the tag pipeline after the full validation matrix.
This first archive release is built and tested before it is published, so an
ISO built from this tag ships the public keyring but not a preconfigured source
stanza; use the commands above once the archive is available.

## What works

- Debian 13 live session, built from the archive with `--apt-recommends false`
- Sway/Wayland desktop: Waybar, foot, fuzzel, mako, swaylock
- Theme rendered from a single palette file into the bootsplash, boot menus
  (ISOLINUX/GRUB), Sway, Waybar, foot, fuzzel, mako, swaylock, GTK3/4, Qt6ct,
  the wallpaper, the console palette, and the installer branding
- Plymouth bootsplash and a KaadzOS identity (`os-release`, `issue`, `motd`)
- Calamares installer that unpacks the live system to disk and boots the
  installed system through greetd — verified unattended in CI for BIOS and UEFI
- Lean default apps: GNOME Web (Epiphany), Thunar, Mousepad, imv, zathura
- Screenshots (Print/Shift+Print) and screen recording to MP4 (`$mod+Print`)
- Eight on-demand packs (`ai`, `android`, `cloudflare`, `creative`, `dev`,
  `gaming`, `privacy`, `windows`) via `kaadzos add <pack>`, with `--dry-run`
- `$mod+a` opens the pack list as a fuzzel menu
- zram swap (zstd, half of RAM) with a swappiness tuned for compressed swap
- Optional signed APT archive with `kaadzos-pack-defs`
- ISO, checksum and keyring mirrored to Cloudflare R2 at stable URLs

## What does not work yet

- No persistence and no fully unattended network install.
- The APT archive currently contains only `kaadzos-pack-defs`; it is not a
  replacement for the Debian archive.
- The live image is unsigned and requires Secure Boot to be off.

## How this build is verified

The release is published by CI only after the validation matrix for the tagged
commit is green. Every push builds the ISO and boots that exact ISO twice in
QEMU — once under Syslinux/BIOS and once under GRUB/OVMF UEFI. The boot test
waits for `KAADZOS_SWAY_READY` on the serial console (emitted only after a
successful `swaymsg` IPC query), dumps the framebuffer, fails the run if
`swaynag` is running, and reports idle RAM with the zram state. A third job
drives the Calamares installer unattended on a blank disk and boots the
installed system, for both firmwares.

The tag pipeline also runs `repo-test`, which builds a throwaway signed APT
repository with an ephemeral key and installs from it in a trixie container.
The `apt-repo` job publishes the real archive to R2 after the full matrix
passes. The release job re-verifies the ISO checksum and publishes the signed
checksum and keyring only after the same matrix is green.

## Known limitations

- A full CI run takes roughly 30–50 minutes; the ISO build alone takes about
  5 minutes and needs about 10 GB of disk.
- The pack manager is POSIX `sh` by design; the base image ships no runtime.
- AMD64 only.
- The `iso.kaadzos.pages.dev` host is a Pages preview branch alias and serves
  the private R2 bucket through a Worker; the production website remains at
  `https://kaadzos.pages.dev`.
