KaadzOS 0.2.1 is a small patch release focused on making the live installer
obvious. The base image, desktop, packs and installer flow are unchanged from
0.2.0.

## What changed

- The live desktop now shows a cyan **Install** button in Waybar. It opens
  Calamares through `kaadzos-install` and disappears on an installed system.
- The welcome terminal prints the MOTD, including `Super+i`, so the installer
  is visible without looking for a desktop icon (Sway has no desktop icons).
- A one-time notification points at the bar button and `Super+i`.
- Debian's upstream `calamares.desktop` entry is hidden in the live image. Its
  `pkexec calamares` path does not pass `/etc/calamares` and does not preserve
  the Wayland environment; the supported launchers are the bar button,
  `Super+i`, and `kaadzos-install`.
- `/etc/os-release`, `/etc/issue` and `/etc/motd` now report 0.2.
- The signed KaadzOS archive is preconfigured in this image. The build checks
  `dists/trixie/InRelease` and writes
  `/etc/apt/sources.list.d/kaadzos.sources` plus
  `/usr/share/keyrings/kaadzos-archive-keyring.gpg`, so `apt update` works on
  the live session and the installed system without the manual setup that
  0.2.0 needed.

## If you are on 0.2.0

Run `kaadzos-install` in a terminal, or press `Super+i`, on the live desktop.
Do not run `calamares` or `sudo calamares`: the raw binary refuses to run as a
normal user, and `sudo calamares` does not get the config path or the Wayland
environment. Re-download only if you want the Install button, the welcome
text, or the preconfigured archive.

## Download

- `KaadzOS-trixie-amd64.iso` (~1.4 GB, hybrid ISO)
- `KaadzOS-trixie-amd64.iso.sha256`
- `KaadzOS-trixie-amd64.iso.sha256.asc` (signed checksum)
- `kaadzos-archive-keyring.asc` (the archive/signing public key)

The ISO is mirrored at:

    https://iso.kaadzos.pages.dev/releases/v0.2.1/

Verify before writing to a USB stick:

    sha256sum --check KaadzOS-trixie-amd64.iso.sha256

To verify the signature as well, import the release key and check the checksum
file:

    curl -fsSL https://iso.kaadzos.pages.dev/releases/v0.2.1/kaadzos-archive-keyring.asc \
      | gpg --import
    gpg --verify KaadzOS-trixie-amd64.iso.sha256.asc KaadzOS-trixie-amd64.iso.sha256

The image is hybrid: the same file boots from a USB stick under BIOS or UEFI.
Secure Boot is supported on the installed system; the live image still requires
Secure Boot to be disabled.

## APT archive

The archive is served at:

    https://iso.kaadzos.pages.dev/apt

This ISO ships the keyring and the source stanza, so an installed system can
run `sudo apt update` immediately. The tag also publishes
`kaadzos-pack-defs` 0.2.1, the canonical pack definitions and hooks under
`/usr/share/kaadzos/packs`.

## How this build is verified

The release is published by CI only after the validation matrix for the tagged
commit is green. Every push builds the ISO and boots that exact ISO twice in
QEMU — once under Syslinux/BIOS and once under GRUB/OVMF UEFI. The boot test
waits for `KAADZOS_SWAY_READY` on the serial console (emitted only after a
successful `swaymsg` IPC query), dumps the framebuffer, fails the run if
`swaynag` is running, and reports idle RAM with the zram state. A third job
drives the Calamares installer unattended on a blank disk and boots the
installed system, for both firmwares.

The tag pipeline also runs `repo-test`, which builds a throwaway signed APT
repository with an ephemeral key and installs from it in a trixie container.
The `apt-repo` job publishes the real archive to R2 after the full matrix
passes. The release job re-verifies the ISO checksum and publishes the signed
checksum and keyring only after the same matrix is green.

## Known limitations

- No persistence and no fully unattended network install.
- The APT archive currently contains only `kaadzos-pack-defs`; it is not a
  replacement for the Debian archive.
- The live image is unsigned and requires Secure Boot to be off.
- AMD64 only.
- A full CI run takes roughly 30–50 minutes; the ISO build alone takes about
  5 minutes and needs about 10 GB of disk.
- The `iso.kaadzos.pages.dev` host is a Pages preview branch alias and serves
  the private R2 bucket through a Worker; the production website remains at
  `https://kaadzos.pages.dev`.
